# Baozi Store

## Sobre o projeto

A Baozi Store é uma loja fictícia de pães chineses chamados Baozi.

Este projeto foi desenvolvido como atividade prática, utilizando Java e Spring Boot, para criar uma API que ajuda a organizar os dados da loja.

## Funcionalidades

- Cadastro de clientes.
- Consulta e exclusão de clientes.
- Cadastro de produtos.
- Consulta e exclusão de produtos.
- Cadastro de pedidos.
- Consulta e exclusão de pedidos.

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- Banco de dados H2
- Maven

## Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute a aplicação pela classe principal.
4. A API estará disponível para realizar os testes.
